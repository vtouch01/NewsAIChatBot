This is an AI chatbot that will provide current up-to-date news with the following commands implemented:

  'us news' - Get top 3 U.S. headlines (Summarized)
  'world tech' - Get top 3 World Technology headlines (Summarized)
  'exit' or 'quit' - Close the chatbot

1) News_chatbot.py - retrieve news updates from https://newsapi.org

2) News_chatbot_llm.py - retrieve news updates from https://newsapi.org and uses Ollama LLM to briefly summarize the news context for user to consume.
